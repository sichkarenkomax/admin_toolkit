# AdminToolkit PowerShell

Набор PowerShell-скриптов для повседневного администрирования и диагностики рабочих станций и серверов Windows.

AdminToolkit объединяет наиболее востребованные административные операции в одном консольном интерфейсе и позволяет выполнять диагностику локального компьютера, сети, Windows, оборудования, служб, домена и удалённых компьютеров.

## Возможности

### Система

* просмотр локальных пользователей;
* просмотр профилей пользователей;
* добавление пользователя в локальные администраторы;
* управление локальными пользователями;
* просмотр устройств и проблемных устройств;
* мониторинг оборудования;
* управление службами;
* управление автозагрузкой;
* диагностика Active Directory и домена;
* работа с журналами событий.

### Сеть

* общая сетевая диагностика;
* IP-адреса, DNS и шлюз;
* Ping;
* Tracert;
* DNS-запросы;
* проверка TCP-портов;
* Test-NetConnection;
* очистка DNS-кэша;
* сброс сетевых компонентов Windows;
* информация о Wi-Fi;
* просмотр сохранённых Wi-Fi профилей.

### Очистка

Безопасная очистка распространённых временных данных:

* кэш 1С и Битрикс24;
* TEMP текущего пользователя;
* Windows TEMP;
* DNS Cache;
* Thumbnail Cache.

Также доступны отдельные операции очистки.

### Программное обеспечение

Установка и обслуживание некоторого стандартного набора программ через WinGet:

* Notepad++;
* Google Chrome;
* UltraVNC;
* WinRAR;
* 7-Zip;
* Everything.

Поддерживаются:

* установка стандартного ПО;
* обновление программ;
* установка отдельного пакета;
* удаление пакета;
* поиск пакетов;
* Pin / Unpin;
* обновление источников WinGet.

### Ремонт Windows

Инструменты восстановления:

1. SFC;
2. DISM CheckHealth;
3. DISM ScanHealth;
4. DISM RestoreHealth;
5. CHKDSK;
6. перерегистрация Windows Apps;
7. перезапуск Explorer;
8. перезапуск Print Spooler;
9. проверка и управление важными службами Windows.

### Удалённое управление

Поддерживается работа с удалёнными компьютерами:

* диагностика компьютера;
* системная информация;
* локальные пользователи;
* службы;
* отправка сообщения;
* перезагрузка;
* выключение;
* проверка WinRM;
* PowerShell Remoting;
* просмотр процессов;
* поиск процессов;
* завершение процессов;
* информация о дисках и свободном месте.

# Требования

## Операционная система

Windows 10 / Windows 11.

Также предполагается возможность работы на Windows Server при наличии соответствующих компонентов.

## PowerShell

Рекомендуется:

```text
PowerShell 7
```

Проверить версию:

```powershell
$PSVersionTable.PSVersion
```

Минимальная версия, указанная в скриптах:

```text
PowerShell 5.1
```

Однако для полноценной работы рекомендуется PowerShell 7.

# Права администратора

AdminToolkit предназначен для административной работы и должен запускаться **от имени администратора**.

Без повышенных прав некоторые функции работать не будут:

* управление службами;
* изменение локальных пользователей;
* некоторые операции восстановления;
* сетевой сброс;
* очистка системных каталогов;
* удалённое администрирование;
* некоторые операции с оборудованием.

При запуске без административных прав Toolkit завершает работу с предупреждением.

# Запуск

## Способ 1. PowerShell

Перейти в каталог Toolkit:

```powershell
cd "C:\***\Admin_TOOLKIT"
```

Запустить:

```powershell
.\AdminToolKit.ps1
```

Если политика выполнения PowerShell запрещает запуск скрипта, можно использовать:

```powershell
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File ".\AdminToolKit.ps1"
```

---

# Запуск через ярлык

Для удобного запуска рекомендуется создать ярлык.

```text
"C:\Program Files\PowerShell\7\pwsh.exe" -NoProfile -ExecutionPolicy Bypass -File "C:\*****\Admin_TOOLKIT\AdminToolKit.ps1"
```

Рабочая папка:

```text
C:\****\Admin_TOOLKIT
```

В свойствах ярлыка:

**Дополнительно → Запуск от имени администратора**

После этого Toolkit можно запускать двойным щелчком.

Работа с программами, запускаемыми через:

# Active Directory / домен

Раздел предназначен для диагностики компьютеров, подключённых к домену.

Доступны:

* обновление групповых политик;
* просмотр результата GPResult;

* проверка контроллера домена;

* проблем с авторизацией.

# 2. Сеть

Раздел предназначен для быстрой диагностики сетевых проблем.

## Сетевая диагностика

Показывает основные параметры активного сетевого подключения.

## IP / DNS / шлюз

Показывает:

* IPv4;
* шлюз;
* DNS;
* сетевые интерфейсы.

## Ping

Проверка доступности узла по ICMP.

## Tracert

Определение маршрута до удалённого узла.

## Resolve-DnsName

Проверка разрешения DNS-имени.

## Test-NetConnection

Проверка сетевого соединения, в том числе конкретного TCP-порта.

## Очистить DNS

Очистка локального DNS-кэша Windows.

## Сброс сети

Используется при серьёзных проблемах с сетевым стеком Windows.

Следует учитывать, что после некоторых операций может потребоваться перезагрузка.

## Wi-Fi

Просмотр информации о текущем Wi-Fi соединении.

## Сохранённые Wi-Fi профили

Просмотр сохранённых беспроводных профилей.

## Проверка портов

Проверка доступности конкретного TCP-порта.

## ARP

Просмотр таблицы соответствия:

```text
IP → MAC
```

Полезно при диагностике локальной сети.

Предоставляет два режима:

### Выполнить команду

Например:

```powershell

```

Команда выполняется непосредственно на удалённом компьютере.

# Принцип разработки

При добавлении новых функций следует придерживаться нескольких правил.

### 1. Не дублировать стандартные средства Windows

Если нужная информация прекрасно доступна в обычном GUI Windows, отдельный пункт не нужен.

Toolkit должен экономить время администратора, а не просто собирать все возможные PowerShell-команды.

### 2. Одна функция — одна задача

Например:

```text
Test-RemoteWinRM
Show-RemoteDisks
Start-RemoteProcesses
```

вместо одной огромной функции на несколько сотен строк.

### 3. Опасные операции требуют подтверждения

Это относится к:

* удалению;
* выключению;
* перезагрузке;
* завершению процессов;
* изменению пользователей;
* изменению служб;
* потенциально разрушительным операциям восстановления.

### 4. Ошибки не должны завершать весь Toolkit

Ошибка отдельной операции должна обрабатываться внутри соответствующей функции:

```powershell
try {
    ...
}
catch {
    Show-Error "..."
}
```

После ошибки администратор должен иметь возможность вернуться в меню.

### 5. Русский интерфейс

Пользовательские пункты меню и сообщения должны быть на русском языке.

Имена PowerShell-функций и системных команд остаются в стандартном английском виде.

# Безопасность

AdminToolkit работает с повышенными привилегиями и способен выполнять потенциально опасные операции.

Особенно осторожно следует использовать:

* удалённую перезагрузку;
* удалённое выключение;
* завершение процессов;
* изменение локальных администраторов;
* остановку служб;
* `PowerShell Remoting`;
* `DISM RestoreHealth`;
* `CHKDSK`;
* сетевой сброс.

Перед выполнением критических операций Toolkit по возможности запрашивает подтверждение.

---

# Рекомендации по эксплуатации

Для рабочих компьютеров рекомендуется разместить Toolkit в общем административном каталоге, например:

```text
C:\AdminToolkit\
```

или использовать сетевой ресурс:

```text
\\server\AdminToolkit\
```

При использовании сетевого варианта необходимо учитывать:

* права доступа к каталогу;
* политики выполнения PowerShell;
* доступность DLL;
* права администратора на рабочей станции.

# Быстрый запуск

После установки PowerShell 7 и копирования Toolkit:

```powershell
cd "C:\AdminToolkit"
.\AdminToolKit.ps1
```

Или через ярлык:

```text
PowerShell 7
    ↓
AdminToolKit.ps1
    ↓
Главное меню
```

# Назначение проекта

AdminToolkit предназначен прежде всего для **быстрой повседневной работы системного администратора**.

Главная задача проекта — не заменить все административные инструменты Windows, а собрать в одном месте операции, которые администратору приходится регулярно выполнять при:

* первичной настройке ПК;
* диагностике неисправностей;
* проблемах с сетью;
* проблемах Windows;
* проблемах с ПО;
* работе с доменом;
* обслуживании оборудования;
* удалённой поддержке пользователей.

**Принцип проекта: меньше пунктов, но каждый пункт должен реально экономить время администратора.**
